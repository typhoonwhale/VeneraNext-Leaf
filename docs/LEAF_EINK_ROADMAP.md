# Leaf5+ 墨水屏开发路线图

更新：2026-11-03。Leaf5+ 当前运行正式版 **1.19.2+253 / ARM64 versionCode 2532**。墨水屏基础 UI、减少动画、紧凑信息区和已知遗漏补齐已发布；历史整合与自动验证见[整合验收](research/2026-11-02-integration-validation.md)。长期状态见 [LEAF_STATUS.md](LEAF_STATUS.md)。

目标是界面清楚、操作及时、动态变化少，同时保留漫画原始灰阶、既有数据和紧凑底栏。设计约束见[官方 SDK 指南](LEAF_EINK_GUIDELINES.md)，组件索引见[墨水屏 UI 指南](LEAF_EINK_UI.md)。不增加漫画灰度转换。

## 阶段与状态

| 阶段 | 工作范围 | 状态 |
|---|---|---|
| 1. 建立基线 | 固定设备、版本和阅读条件，记录已有问题 | Leaf Activity 为 350 dpi、fontScale 0.85；设备运行 1.19.2 / 2532 |
| 2. 黑白 UI | 主题、控件、阅读器等界面的对比度和信息布局 | 基础模式随 1.19.0 发布；紧凑信息区及图片收藏缩略图边框修复随 1.19.2 发布 |
| 3. 减少动态效果 | 对话框、加载和布局动画；保留必要的滚动与缩放 | 基础模式随 1.19.0 发布；直接对话框及加载／动态尺寸遗漏随 1.19.2 补齐 |
| 4. SDK 手动刷新 | 探测官方接口、单次刷新、系统模式冲突与退出恢复 | 低优先级候选；未安排实机实验，不默认开启 |
| 5. 自动刷新策略 | 仅在手动刷新验证有效且仍有残影问题时评估 | 无当前计划；不预设按页全刷或自动刷新 |
| 6. 能耗对照 | 固定内容、亮度、网络与操作节奏比较耗电 | 低优先级候选；尚无对照结果 |

阶段 4 是阶段 5 的前置条件。后续只有出现明确需求时才启动硬件试验；系统策略足够时保持原样，不引入自动全刷。

## 实机与截图边界

当前设备配置为 Leaf Activity 350 dpi、fontScale 0.85。ADB 系统截图可以对照系统渲染和布局，不呈现墨水屏面板灰阶、闪烁或残影。历史模拟截图也不作为面板体验验收。

## 能耗约束与测量方法

目标是在同等使用条件下避免可重复、超出测量波动的耗电回归。测量前不承诺零增长；整数电量下单次 1% 变化不足以单独下结论。

- 不为墨水屏适配增加周期性全刷、常驻保活或高频电量／设备状态轮询。
- 硬件刷新如未来启用，应按有效事件触发，并处理重复请求、快速翻页、取消、退出和休眠。
- 不顺带改动图片预加载、缓存及时钟／电池逻辑；不以持续全屏滤镜或逐帧处理改变漫画画面。
- 新 SDK 或插件需核对包体积、启动和后台行为；不默认启用自动刷新。
- 对照时固定设备、固件、系统模式、前光、网络、缓存、内容和操作节奏，记录时长、电量与中断。首次采样可用正常阅读 60 分钟；整数电量变化不足时延长窗口或重复比较。休眠与主动阅读分开记录。

若后续启动开发，复用现有设置与作用域，明确新增默认值和旧设置迁移。UI 自动验证与硬件／耗电实测分别记录；证据不足时维持待定状态。

## 已实现

“关于 → 检查更新”取得同一 GitHub Release 的版本、说明和唯一 ARM64 APK，校验上传状态、大小、SHA-256 和下载地址；下载完成后进一步校验真实内容、Android 包名、签名、版本和 ABI。随后由用户授权未知来源安装，并在系统安装器确认。Debug 不开放正式包原位更新，其他平台保留发布页流程。

唯一应用级控制器负责 `cacheRoot/updates/`：不续传、失败从零重试、取消等待传输与文件句柄收尾、启动删除半包。它在初始化后独立执行恢复，不依赖启动检查开关或联网。正常漫画缓存仍由 `CacheManager` 管理 `cacheRoot/cache/`；导入、分享等调用使用各自临时子目录，未发现新增更新目录被既有全根清理覆盖的链路。

原生安装记录独立保存于 SharedPreferences，使用 attempt ID 和进程身份关联 ActivityResult。结果未知时保留唯一完整包；即使系统回收 APK，原生未结束的占用仍阻止重下与覆盖。只有实际系统包身份和版本达到目标，或对应安装明确取消/失败，才释放占用；权限页与安装器往返不会误删 APK。

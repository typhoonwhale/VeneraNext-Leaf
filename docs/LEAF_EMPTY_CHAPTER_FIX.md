# 空章节加载错误与重试

更新：2026-10-31。修复实现 `c8eb87a` 已随 PR #4 合入 main `ccbf3f7`。本修复版准备以 1.19.1 发布，不包含 `feature/leaf-read-state` 的“已读/看过”规则。

## 问题

瓜子等漫画源在请求失败、HTTP 非 200 或解析不到图片时可能返回空列表。客户端此前接受空列表后继续计算页码，可能触发 `Invalid argument(s): 1`，导致整页错误、没有重试入口并无法翻页。

实际安装的瓜子脚本版本为 1.0.4，内容与此前诊断快照一致。固定脚本、QuickJS、加载器和 Reader 组件的本地探针复现了空列表边界。真实瓜子尝试未复现原错误，首次网络或解析失败原因及原异常栈仍未确定。

## 修复行为

- 在线章节返回空图片列表时，显示“本章未返回任何图片，请重试。”，通过现有“重试”按钮重新请求。
- 空结果不进入已就绪状态、不消费跳至末页请求，也不写入零页阅读进度；零页状态增加页码边界防御。
- 瀑布流邻章失败时保留已加载章节，并可通过原有重试入口再次加载。
- 请求取消机制保持原状；本次没有新增取消机制，也没有据此声称解决旧请求污染。

空结果的零页状态防御与未加载时的 `images == null` 是两条路径。初次加载失败的悬浮信息仍显示 1/1 占位，这是未加载状态的显示遗留；它不表示有效页数，也不写零页历史。本次不修改该显示。

## 验证

- PR #4 的 8 项检查通过；完整 Linux Flutter 测试为 5543 项通过、151 项跳过。
- 固定签名 ARM64 Release `1.19.0-emptyfix.1 / 2502` 在 Leaf5+ 同码覆盖成功；安装前后比对确认已有源、设置、历史、收藏和 Cookie 数据保留。
- 受控空列表显示重试提示，重试恢复 3 张图片；延迟 30 秒的请求期间退出重入、旧请求完成后保持正常并继续翻页，均通过。
- 真实瓜子《噬谎者》第 22 话重入后正常显示 1/19，未复现原偶发错误。测试后已恢复原 `1.19.0 / 2502`。

以上实机验证仅覆盖同版本码 Release 覆盖，不是跨版本升级或应用内更新验收。1.19.1 尚未发布；本修复不证明所有瓜子网络失败均已解决，也不声称旧请求污染问题已解决。

# 空章节加载错误与重试

更新：2026-10-31。实现提交 `c8eb87a` 已随 PR #4 合入 main `ccbf3f7`，并包含在正式版 [Leaf 1.19.1 / 2522](https://github.com/typhoonwhale/VeneraNext-Leaf/releases/tag/v1.19.1) 中。发布只含空章节修复，不包含 `feature/leaf-read-state` 的已读/看过功能；本地修复工作区版本配置仍为 `1.19.0+250`。

## 问题与归属

用户报告瓜子漫画章节首次加载中返回、再次进入后显示整页 `Invalid argument(s): 1`，没有重试按钮，翻页也无法恢复。公开瓜子 1.0.4 脚本在网络失败、HTTP 非 200 或解析没有图片时会返回空列表。客户端此前接受这一结果，随后页码计算 `clamp(1, 0)` 抛出构建异常，进入仅显示异常文字的全局 ErrorWidget。

固定脚本与真实 QuickJS、加载器、Reader 组件的本地探针已复现这一边界；受控退出重入没有发现旧请求覆盖新请求。10-31 已通过设备备份取得实际安装脚本，version 为 1.0.4，内容与先前诊断快照完全一致。真实瓜子尝试未复现原错误，现有设备日志也没有原异常栈；首次空结果的网络/解析原因仍未确定，不能据此认定是取消机制或缓存损坏。

## 修改后的行为

- 在线结果没有图片时，章节加载失败并显示“本章未返回任何图片，请重试。”，使用现有错误页的“重试”按钮重新请求。
- 在拒绝空结果前检查请求是否已取消；退出后的迟到结果保持取消语义，不发布给新阅读器。
- 本地章节不可用时，只有有效的非空在线结果才报告已回退在线阅读。
- 空结果不进入 ready、不消费跳到末页请求，也不写入零页阅读进度。瀑布流邻章失败时保留已加载章节，通过原有重试入口再次加载。
- 即使 UI 收到零页列表，底部章页标签显示 P0，信息页脚和悬浮页码显示 0/0；正常页码行为保留。首次加载失败时 images 仍为 null，悬浮信息目前保留 1/1 占位显示，尚未统一为空状态。

不修改源脚本、缓存、网络取消或历史数据规则，不增加自动重试。

# Leaf 当前状态与分支说明

更新：2026-10-31。正式版为 **1.19.0 / versionCode 2502**。空章节修复已通过 PR #4 合入 main `ccbf3f7`，8 项 PR 检查通过；完整 Linux Flutter 测试为 5543 项通过、151 项跳过。

当前正在准备 **1.19.1+252**（ARM64 versionCode 2522），仅包含空章节修复，基于已合入 main 的修复。版本尚未发布或安装到设备；1.19.1 的“已读/看过”规则不在本次版本中，仍需单独验收。

## 修复与验证范围

- 瓜子等源在请求或解析失败后返回空图片列表时，章节显示“本章未返回任何图片，请重试。”，可使用现有“重试”按钮再次请求。
- 空结果不进入已就绪状态、不消费跳至末页请求，也不写入零页阅读进度；零页页码边界有防御处理。
- 固定签名 Release `1.19.0-emptyfix.1 / 2502` 已在 Leaf5+ 通过同版本码覆盖、数据比对、空列表重试恢复、延迟 30 秒的请求期间退出重入及后续翻页。测试结束后恢复原 `1.19.0 / 2502`。
- 这次只验证同版本码覆盖，不代表 1.19.0 到 1.19.1 的跨版本升级或应用内更新已验收。1.19.1 尚未发布。

## 已知边界

实际瓜子源脚本为 1.0.4，与先前诊断快照一致；真实瓜子尝试未复现原错误，首次空结果的现场原因和原异常栈仍未知。该修复处理客户端收到空图片列表后的行为，不证明解决所有瓜子网络失败，也不声称修复旧请求污染。

初次加载失败时，悬浮信息仍可能显示未加载状态的 1/1 占位；该值不是实际页数，不进入已就绪状态，也不会写入零页历史。本次没有修改这项显示遗留。请求取消机制沿用既有实现。

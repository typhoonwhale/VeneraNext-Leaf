## 结论与建议顺序

先做**黑白高对比 UI + 减少非必要动画 + 复用无动画翻页**，再做实机刷新对照；文石 SDK 的硬件刷新控制放到后续验证阶段。目标是内容清楚、操作及时、画面稳定，不是简单降低或提高整个应用的帧率。

使用者提出黑白 UI 是合理方向。建议白色背景、黑色正文和控件轮廓，用勾选、边框、文字区分状态；少量灰色用于次要层级。黑白界面不等于将漫画图像阈值化成纯黑白：漫画网点、阴影和封面仍需保留灰阶及原始图像数据，默认不要用全应用滤镜一起处理。仅把彩色主题去饱和也不够，相近明度会导致选中、禁用和普通状态难以分辨。

| 优先级 | 方向 | 本项目建议 | 验收重点 |
|---|---|---|---|
| P0 | 黑白高对比主题 | 统一背景、文字、按钮、选中状态、分隔线；检查绕过主题的红色错误、绿色进度等 | 不依赖颜色即可认出状态；浅灰字、禁用按钮仍能看清 |
| P0 | 减少动画 | 取消路由切换、菜单淡入、图片渐入、水波纹等装饰帧；保留立即可见的按下/选中反馈 | 点击及时生效，关闭动画后对话框/菜单不会卡住或不可点 |
| P0 | 翻页和图片加载 | 优先画廊分页与现有关闭翻页动画选项，保留合理预加载 | 单次操作只到预期页；缓存命中不闪占位图，漫画细节不被破坏 |
| P1 | 加载及状态信息 | 静态加载提示或按有效进度更新；时钟按分钟显示，电池仅在变化时更新 | 网络慢时仍能区分加载/失败/完成；后台不继续空转 |
| P1 | 滚动与按键 | 书架/设置保留必要滚动；减少惯性效果需单独评估；核对实体键、长按、快速连按 | 不盲目去抖丢操作，不影响缩放拖动和可达性 |
| P1 | 系统刷新模式对照 | 同一漫画在设备提供的画质优先与快速模式下对照 | 残影、灰阶细节、响应时间、闪屏频次分别记录 |
| P2 | 硬件清残影 | 确认固件及 Flutter 渲染兼容性后，再考虑 BOOX 原生接口桥接 | 真正硬件刷新有效、生命周期可恢复、失败可回退 |

## “刷新快一点还是慢一点”需要拆成三件事

1. **应用画面变化频率**：页面切换的 200–300 ms 动画会绘制很多中间画面。墨水屏上通常应直接显示最终状态，而不是拉长动画或人为延迟点击。必要的缩放、拖动仍需及时响应。
2. **屏幕刷新模式**：由系统/驱动决定画质与速度的取舍。快速模式适合滚动，但可能增加残影或损失细节；静态漫画通常先选画质优先模式。模式名称、支持范围和实际效果由设备固件决定，不能把别的 BOOX 机型参数直接套给 Leaf5+。
3. **清残影/全刷频率**：清残影有视觉打断和耗时，应按残影程度取舍。不要默认每次点击、时钟更新或每翻一页都强制全刷，也没有本轮证据支持固定“每 N 页最佳”。

Flutter 的 `build`/`setState`、引擎帧率和面板物理刷新不是一回事。一次 widget 重建不必然导致整屏刷新；减少重建可能降低 CPU 开销，却不能证明减少了面板全刷。反之，应用端纯色闪屏会产生画面变化，但不能保证驱动使用真正的全刷波形。

## 官方依据及适用边界

本轮关键摘录保存在[来源记录](evidence/2026-10-25-eink-official-sources.json)。网页使用浏览器读取可见正文；SDK 文档使用 GitHub API 固定 commit 读取。记录为摘录，并非完整网页离线快照。

- [BOOX 第三方应用优化说明](https://support.boox.com/#/document/6a72f173e7311e5c36b2c396)：阅读类 App “多为静态内容，则使用标准/净清模式优先保证画质即可”；滚动类 App 可使用快速或极速模式。它是通用建议，当前 Leaf5+ 固件实际菜单尚待核对。
- [BOOX SDK 开发指南](https://github.com/onyx-intl/OnyxAndroidDemo/blob/ec512c79c0d39c1e294214d36580ce4c914bbea6/doc/Eink-Develop-Guide.md)：建议黑白灰主色、不在图文上增加透明层、分页加载内容、尽量避免动画。指南还建议字体不小于 14sp、中央按钮图标不小于 36dp × 36dp、边缘不小于 48dp × 48dp。这些是通用开发建议，不是设备硬性限制；Flutter 字体还受 text scaling 影响，不能直接等同物理像素。用户已明确要求的小底栏 15–25、字号 9–13 本轮保持原样，其可读性单独实测，不据此擅自放大。
- [官方 Update Mode 文档](https://github.com/onyx-intl/OnyxAndroidDemo/blob/ec512c79c0d39c1e294214d36580ce4c914bbea6/doc/EPD-Update-Mode.md)：GU 为 16 级灰局刷，GC 为 16 级灰全刷，ANIMATION 更快但质量更低；REGAL 面向文字，不能据此认定最适合含网点和大面积黑块的漫画。
- [官方刷新 API 示例](https://github.com/onyx-intl/OnyxAndroidDemo/blob/ec512c79c0d39c1e294214d36580ce4c914bbea6/doc/EPD-Screen-Update.md)确有 `EpdController.invalidate(view, UpdateMode.GC)` 等接口；[控制器说明](https://github.com/onyx-intl/OnyxAndroidDemo/blob/ec512c79c0d39c1e294214d36580ce4c914bbea6/doc/EpdController.md)建议应用使用 `EpdDeviceManager` 包装。公开接口存在不等于已验证 Leaf5+ 固件或 Flutter Surface 可用，本轮未接入 SDK。

- [Leaf5+ 产品页](https://zh.boox.com/product-ad/?id=5499)已核对标题；本轮未从宣传图片提取全部硬件参数，也未读取实机固件、DPI、刷新波形或耗电数据。

## 当前源码已具备的能力

以下为固定基线源码核对，不是本轮新增功能。

- [阅读偏好](../../lib/foundation/reader_preferences.dart)已提供 `enablePageAnimation`（默认 true）及 `eInkRefreshEnabled`（默认 false）。[阅读设置](../../lib/features/settings/reader.dart)已有“翻页动画”和“电子墨水屏刷新”入口，可在开始开发前对照体验。
- E-Ink 参数当前为时长默认 100 ms、可选 100–1500 ms；间隔默认 1、可选 1–10 次；样式为黑、白、先白后黑。它们是**软件闪屏设计值**，不是硬件刷新率、物理刷新完成时间或最佳清残影周期。
- [刷新控制器](../../lib/features/reader/eink_refresh_controller.dart)计算翻页计数；[刷新覆盖层](../../lib/features/reader/eink_refresh.dart)用 `ColoredBox` 与 `Timer` 盖上并移除纯色；[阅读 scaffold](../../lib/features/reader/scaffold.dart)接入，仅面向 Gallery 模式。没有理由因存在此设置就宣称已使用 BOOX 原生全刷。
- [外观设置](../../lib/features/settings/appearance.dart)与[应用偏好](../../lib/foundation/application_preferences.dart)已有明暗主题和多种彩色主题，但没有专门的黑白高对比选项。新增黑白主题应覆盖组件语义，不能只修改主题 seed。
- 部分菜单、阅读控件已响应 `MediaQuery.disableAnimationsOf(context)`；不能据此认定全应用均无动画，需要检查其余自定义动画与图片渐入。
- [状态轮询](../../lib/features/reader/status_polling.dart)与[状态栏](../../lib/features/reader/status_info.dart)已有值变化判定，不能将“1 秒检查”描述成“每秒整屏刷新”。后续优化计时器应先测耗电及生命周期行为。

## 建议的第一阶段范围

建议沿用现有偏好存储，提供可切换的墨水屏外观/减少动态效果策略；不在渲染层全局加灰度滤镜，不强制覆盖所有用户旧设置。新增默认值与已有用户设置迁移方式需在实施时明确。

第一阶段覆盖首页、书架、详情、设置和阅读菜单的黑白控件，以及装饰动画和图片淡入。保留漫画原图、阅读进度、数据备份和固定 Release 身份；不改变此前已调好的底栏高度/字号。原有“电子墨水屏刷新”先维持可选，不能与系统全刷叠加后仍默认每页闪屏。

第二阶段先用系统提供的刷新模式与手动全刷建立实机对照。如果 UI 改进后仍存在明显残影，再决定是否接入硬件刷新，并验证 Flutter 渲染目标、前后台切换、设备检测、SDK依赖、失败回退和系统自身策略的交互。不要先给所有刷新位置加固定延时，或未经验证直接调用隐藏 API。

## 验证方案与未决项

本轮只做源码和公开资料调查；没有修改运行代码、构建新 APK 或执行实机测量。待开发后应分开验证：

1. 自动验证：黑白主题下普通/选中/禁用/错误状态可区分；关闭动画不破坏菜单、对话框和翻页；设置持久化、继承及旧数据恢复正常。按实际修改运行对应测试，不以截图替代逻辑测试。
2. 静态真机观察：同一套文字、网点、渐变、大黑块漫画，检查灰阶损失、分隔线、灰字和小底栏可读性。保留原图和原设置作为对照。
3. 动态真机观察：普通翻页、快速连翻、开关菜单、返回书架、滚动列表、双击缩放、拖动及切后台。建议以同一段 20 页作为固定对照序列；20 页仅为测试长度，不是全刷间隔建议。
4. 一次只改变一个变量：先动画开/关，再系统模式，再软件闪屏开/关，最后才比较原生清残影。记录固件、模式、闪屏参数、页码和操作，使用拍摄设备屏幕的视频观察残影；应用截图无法记录电子纸粒子的残影。
5. 耗电单独比较：相同亮度、网络、缓存和阅读时长；本轮无数据，不承诺黑白主题会降低多少耗电或翻页变快多少。

未决：Leaf5+ 当前固件的刷新选项、系统对第三方 Flutter 应用的优化、系统全刷与软件闪屏是否重复、原生接口兼容性，以及用户对静态画质与翻页延迟的实际取舍。

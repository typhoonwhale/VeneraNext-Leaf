# Leaf5+ 墨水屏“看过”圆圈过小

记录：2026-11-02，2026-11-03 完成验证。用户在正式 1.19.2 / ARM64 2532 上反馈章节列表的“看过”圆圈过小，ADB 截图确认它明显小于相邻的“已读”勾。问题归属客户端章节状态 UI，与漫画源及读状态计算无关。

## 实机比例

本次连接的 Leaf5+ 为 Android 13，截图为 1264 × 1680。系统 `wm density` 返回 300 dpi，但正式 Leaf 前台 Activity 的 `mCurrentConfig` 是 **350 dpi、577 × 768 dp、fontScale 0.85**。两者属于不同配置层，后续按应用的 350 dpi 和字体缩放 0.85 核对布局。

由 Activity density 可推得 DPR 2.1875；未直接读取 Flutter MediaQuery，不把此值写成 Flutter 实测。此前 DPR 2.25、字体缩放 1 的本地模拟仍为历史估算，不能代替这次应用配置。截图只证明布局和对比度，面板残影与实际墨迹仍需用户观察。

## 原因与修复

墨水屏的已读勾使用 `EInkCheckMark`，以 14 dp 尺寸和 2.5 dp 线宽独立绘制；看过状态却使用 `Text('○')`，实际圆圈受字体字形、默认字号及系统字体缩放共同影响，导致直径和线宽均偏小。

`EInkViewedMark` 改为外径 14 dp、线宽 2.5 dp 的矢量空心圆，与已读勾共用尺寸常量。圆心位于控件中央，路径向内留出半个线宽，保证描边不裁切。黑底使用白圈，白底使用黑圈；字体缩放不再缩小圆圈。标题仍响应字体缩放，圆圈与标题保持 4 dp 间距。普通模式、已读勾及状态判定保持原行为。
